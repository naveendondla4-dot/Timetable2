# Anusha Boys Hostel Website

A responsive single-page website inspired by the supplied hostel mess-menu poster and CSE timetable.

## Files
- index.html — page content
- style.css — responsive design
- script.js — Mess Menu / Class Timetable tabs

## Run
Open `index.html` in Chrome/Edge/Firefox. No server or installation is required.

The timetable/menu text can be edited directly in `index.html`.


## Install as an app
This is now a **PWA (Progressive Web App)**. When hosted on HTTPS, supported browsers can show **📲 Install App** and users can install it on Android like an app. It also works offline after the first load.

For Chrome Android, open the hosted website and use **Install app** / **Add to Home screen** if the install button is not shown.
